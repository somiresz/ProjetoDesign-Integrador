# Histórias de Usuário da Plataforma Mosaico

## 1. Apresentação

As histórias de usuário descrevem as funcionalidades da plataforma considerando as necessidades de quem irá utilizá-la.

Cada história apresenta o perfil do usuário, a ação desejada e o benefício esperado, acompanhados dos respectivos critérios de aceitação.

## 2. Histórias de usuário

### HU01 – Selecionar símbolos para comunicação

**História:** Como estudante, quero selecionar símbolos e imagens para expressar minhas necessidades, para facilitar minha comunicação no ambiente escolar.

**Critérios de aceitação:**
- O painel deverá apresentar símbolos e imagens selecionáveis.
- O estudante deverá conseguir selecionar mais de um elemento.
- Os elementos selecionados deverão aparecer na mensagem em construção.

### HU02 – Reproduzir uma mensagem em áudio

**História:** Como estudante, quero ouvir a mensagem que construí, para facilitar a compreensão e a comunicação com outras pessoas.

**Critérios de aceitação:**
- A mensagem construída deverá permanecer visível.
- Deverá existir uma opção de reprodução em áudio.
- O recurso deverá informar quando não estiver disponível no dispositivo.

### HU03 – Utilizar uma interface de comunicação organizada

**História:** Como estudante, quero encontrar os recursos de comunicação de maneira simples, para conseguir utilizar a plataforma com maior autonomia.

**Critérios de aceitação:**
- Os símbolos deverão estar organizados visualmente.
- Os elementos deverão apresentar identificação compreensível.
- A interface deverá permitir ajustes de apresentação previstos no sistema.

### HU04 – Organizar materiais pedagógicos

**História:** Como professor, quero adicionar e organizar materiais pedagógicos, para facilitar o planejamento das atividades escolares.

**Critérios de aceitação:**
- O sistema deverá permitir adicionar materiais.
- Os materiais deverão ser apresentados de maneira organizada.
- O professor deverá conseguir visualizar os materiais cadastrados.

### HU05 – Adaptar conteúdos pedagógicos

**História:** Como professor, quero receber sugestões de adaptação de materiais, para atender às diferentes necessidades de aprendizagem dos estudantes.

**Critérios de aceitação:**
- O sistema deverá permitir selecionar um conteúdo para adaptação.
- Deverá apresentar uma sugestão de conteúdo adaptado.
- A sugestão deverá ser identificada como conteúdo gerado ou sugerido por inteligência artificial.
- O professor deverá poder revisar o resultado.

### HU06 – Aprovar materiais adaptados

**História:** Como professor, quero revisar e aprovar os materiais adaptados antes de compartilhá-los, para garantir que estejam adequados à atividade pedagógica.

**Critérios de aceitação:**
- O material sugerido deverá permanecer em revisão até a aprovação.
- O professor deverá conseguir editar o conteúdo.
- O compartilhamento deverá ocorrer somente após a aprovação.

### HU07 – Acompanhar atualizações pedagógicas

**História:** Como familiar ou responsável, quero visualizar as atualizações pedagógicas compartilhadas pela escola, para acompanhar a participação e o desenvolvimento educacional do estudante.

**Critérios de aceitação:**
- O sistema deverá apresentar as atualizações disponibilizadas pela escola.
- As informações deverão estar organizadas por data.
- O usuário deverá visualizar somente informações às quais tenha autorização de acesso.

### HU08 – Consultar informações como profissional de apoio

**História:** Como profissional de apoio autorizado, quero consultar informações pedagógicas compartilhadas, para acompanhar o estudante e contribuir com a continuidade das estratégias educacionais.

**Critérios de aceitação:**
- O acesso deverá ser autorizado previamente.
- O profissional deverá visualizar apenas as informações disponibilizadas para seu perfil.
- O sistema deverá impedir o acesso a informações sem permissão.

## 3. Considerações finais

As histórias de usuário representam as principais interações previstas para a plataforma. Elas servirão como base para a construção das telas, o planejamento do protótipo e a definição das tarefas de avaliação da Etapa 6.
