# Projeto Integrador – Design Profissional

**Laboratório de Carreira e Inovação Responsável em TI**

## Sobre o projeto

Este projeto tem como objetivo investigar as exigências do mercado de trabalho em Tecnologia da Informação, desenvolver competências profissionais e propor uma solução tecnológica para um problema social ou ambiental.

## Objetivos

- Investigar o mercado de trabalho em TI.
- Analisar competências profissionais e planejar carreiras.
- Estudar ética, inteligência artificial e cidadania digital.
- Investigar um problema social ou ambiental.
- Desenvolver e avaliar uma proposta de solução tecnológica.
