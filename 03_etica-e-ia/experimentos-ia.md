# Experimentos com Ferramentas de Inteligência Artificial

## 1. Objetivo

O objetivo dos experimentos é analisar a utilização de diferentes ferramentas de inteligência artificial em atividades de programação, banco de dados e compreensão de conceitos tecnológicos, avaliando suas respostas, limitações e possíveis erros.

## 2. Registro dos experimentos

### Experimento 1 – Validação de e-mail

- **Integrante responsável:** Davi Ataíde
- **Ferramenta:** Claude (Anthropic)
- **Prompt utilizado:**

  "Crie uma função em JavaScript para validar o formato de um e-mail e garantir a acessibilidade de um formulário de login."

- **Resposta obtida:**

  A IA atendeu aos requisitos do prompt e criou um exemplo em HTML com uma tela para inserir e-mails.

- **Avaliação crítica:**

  A ferramenta conseguia identificar o que estava sendo digitado na caixa de entrada e solicitava correção quando o formato não correspondia ao padrão esperado, como a ausência de "@.dominio.com". Entretanto, o formulário não armazenava o e-mail informado.

### Experimento 2 – Consulta SQL

- **Integrante responsável:** Vitor Oliveira
- **Ferramenta:** ChatGPT (OpenAI)
- **Prompt utilizado:**

  "Escreva uma consulta SQL para extrair a média de vendas por cliente e otimizar a estrutura para um banco de dados PostgreSQL."

- **Resposta obtida:** A preencher com o resultado real do experimento.
- **Avaliação crítica:** A preencher após analisar a resposta.

### Experimento 3 – Modelos de inteligência artificial

- **Integrante responsável:** Lindsay
- **Ferramenta:** Gemini (Google)
- **Prompt utilizado:**

  "Explique a diferença entre modelos preditivos e modelos de classificação para um público não técnico de negócios."

- **Resposta obtida:** A resposta explica que os dois modelos são utilizados para analisar dados e gerar resultados, mas possuem objetivos diferentes. A principal diferença está no resultado: um estima valores numéricos, enquanto o outro prevê categorias ou classes.
- **Avaliação crítica:** A resposta do Gemini está correta, mas apresenta uma simplificação conceitual importante: modelos de classificação também são modelos preditivos. Ou seja, a resposta é útil para iniciantes, mas poderia ser mais precisa para evitar confusões sobre os conceitos de IA e ML.

### Experimento 4 – Desenvolvimento de API

- **Integrantes responsáveis:** Grupo (Lindsay, Vitor e Davi)
- **Ferramenta:** GitHub Copilot
- **Prompt utilizado:**

  "Gere o código de uma API RESTful em Python (FastAPI) com suporte a banco de dados PostgreSQL."

- **Resposta obtida:** A ferramenta apresentou uma estrutura inicial de API utilizando Python e FastAPI, com possibilidade de integração ao PostgreSQL. O exemplo incluiu a criação de rotas HTTP, conexão com o banco de dados e operações básicas para cadastrar, consultar, atualizar e excluir registros.
- **Avaliação crítica:** A resposta demonstrou como o GitHub Copilot pode auxiliar na criação da estrutura inicial de uma API, facilitando o desenvolvimento e economizando tempo. Entretanto, o código gerado precisa ser revisado e testado antes de ser utilizado. Também seria necessário configurar corretamente a conexão com o PostgreSQL, proteger as credenciais do banco de dados e implementar mecanismos de autenticação e segurança, caso a aplicação exigisse essas funcionalidades. Como o exemplo é uma estrutura inicial, ele não garante uma aplicação pronta para produção. É necessário verificar a compatibilidade das bibliotecas, testar as operações e revisar possíveis falhas de segurança.

## 3. Análise geral

Os experimentos demonstram diferentes possibilidades de utilização da inteligência artificial, desde a validação de formulários até consultas SQL, explicações conceituais e desenvolvimento de APIs.

A análise das respostas permite observar que, apesar de auxiliarem na execução de tarefas, essas ferramentas precisam ser avaliadas e testadas. Uma resposta aparentemente correta pode apresentar limitações ou não atender completamente ao objetivo solicitado.

## 4. Conclusão

A utilização de ferramentas de inteligência artificial pode contribuir para a produtividade e a aprendizagem dos profissionais de tecnologia. Entretanto, é fundamental verificar os resultados, identificar possíveis falhas e manter a supervisão humana durante sua utilização.
